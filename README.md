# Vigilix

Real-time intelligent video analytics platform for object detection, tracking, and surveillance event analysis.

## Core stack

- Python, FastAPI
- OpenCV
- PyTorch
- Ultralytics YOLO
- ByteTrack
- React + TypeScript
- PostgreSQL
- Redis
- Docker

## Planned capabilities

Vigilix is being built around a modular video-processing pipeline: video ingestion, object detection, multi-object tracking, surveillance analytics, event generation, backend APIs, and a browser-based monitoring dashboard.

The first working milestone focuses on a clean FastAPI service, OpenCV video ingestion, and a detector abstraction that can later support real-time analytics.

## Development

Backend setup and local run instructions will be added as the first implementation milestone is completed.
